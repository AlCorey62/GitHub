# Brouillons

Articles et publications rédigés mais pas encore validés par Damien, sans date de parution. Rien ici n'est publié : la publication programmée ne lit que `a-paraitre/` et `semaines/`.

À la validation :
1. choisir le jour de parution et le reporter dans la configuration des pages (`"date"`) et dans `publications.md` ;
2. déplacer `article/` vers `a-paraitre/AAAA-MM-JJ-nom/` ;
3. reporter la publication du jour dans la semaine concernée (`semaines/AAAA-MM-JJ/publications.md`, avec son visuel) ;
4. passer le sujet à « validé » dans `calendrier.md`.

|---|---|---|---|
