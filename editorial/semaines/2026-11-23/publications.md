**LinkedIn**

> B0, BR, B2V, BC : savez-vous lire une habilitation électrique ?
>
> Le symbole se lit caractère par caractère. Le premier donne le domaine de tension : B pour la basse tension, H pour la haute. Le deuxième, le type d'opération : 0 pour des travaux non électriques, 1 pour un exécutant, 2 pour un chargé de travaux, R pour une intervention générale, C pour une consignation. Le troisième apporte une précision, comme V pour le voisinage renforcé.
>
> C'est l'employeur qui délivre l'habilitation, après une formation. Le Code du travail l'impose pour toute opération sur une installation électrique ou dans son voisinage.
>

> Inverseur de sources : que se passe-t-il quand le réseau tombe ?
>
> L'inverseur bascule l'alimentation d'une source à l'autre, par exemple du réseau vers un groupe électrogène de secours. Un verrouillage empêche les deux sources d'alimenter le circuit en même temps.
>
> Ce basculement, manuel ou automatique, s'accompagne en général d'une brève coupure. Pour les équipements qui ne la supportent pas, il existe le groupe Twin zéro coupure.
>
